# 台灣經濟論文叢刊 (TER) 中文寫作規範

參考期刊：《經濟論文叢刊》(Taiwan Economic Review)，國立臺灣大學經濟學系出版。

---

## 一、引用格式

- 內文引用採「作者姓名 (年份)」格式，括號為**半形**，例如：`Fu (2006)`、`Hurley and Shogren (1998)`
- 兩位作者之間用 `and`，三位以上列出全部，例如：`Baik, Lee, and Lee (2022)`
- 引用嵌入句子中，作者名作主詞：
  - ✓ `Fu (2006) 指出...`
  - ✓ `Hurley and Shogren (1998) 發現...`
  - ✗ 不以引用開頭後直接接結論，缺少動詞連結
- 括號型引用（非主詞）：`...（Fu, 2006）`
- 連續引用多篇：`Wang (1998)、Kamien and Tauman (2002) 與 Filippini (2005) 皆發現...`

---

## 二、主詞與人稱

- 全文以「**本文**」作為論文主詞，例如：「本文假設...」、「本文的主要結果有三點」
- 「**我們**」可作補充主詞，但不作句首主詞，例如：「就我們所知...」
- 避免使用第一人稱「我」

---

## 三、句式與段落

- 每段以**主題句**開頭，明確說明該段重點
- 句子長度適中，避免一句到底超過三個分句
- 列舉項目用頓號 (、) 分隔，較長的並列項目用分號 (；)
- 段落縮排：首行縮排兩字元

---

## 四、緒論結構

1. **開場**：從現實現象或廣泛背景切入，引出研究問題
2. **本文修正 / 出發點**：說明與基準文獻的差異，指出信念或機制層面的精確修正
3. **文獻脈絡**：以邏輯串連相關研究，不條列，而是以「XXX 發現...；YYY 則進一步指出...」的方式推進
4. **本文模型**：說明設定與具體例子
5. **主要結果**：「本文的主要結果有三點。第一，...。第二，...。第三，...。」
6. **貢獻定位**：「就現有文獻而言，...尚未被明確討論。」
7. **後文安排**：「後文安排如下。第二節...；第三節...；...；第 N 節總結。」

## 五、術語統一

| 英文 | 中文 |
|------|------|
| contest | 競賽 |
| rent-seeking | 尋租 |
| asymmetric information | 訊息不對稱 / 資訊不對稱（擇一統一） |
| separating equilibrium | 分離均衡 |
| pooling equilibrium | 混合均衡 |

| best response | 最佳反應 |
| prior / posterior belief | 事前 / 後驗信念 |
| endogenous timing | 內生時序 |

## 六、數學符號

- 行內數學用 `$...$`，例如 `$mu$`、`$delta$`、`$V$`
- 緒論中避免大量行內公式，優先以文字描述結果
- 符號首次出現須說明含義，例如「平均獲勝評價 $mu$」

---

## 七、其他注意事項

- 使用中文標點：，。；：「」（全形）
- 括號內的英文作者名與年份用半形括號 `()`
- 腳註用於補充說明，不放入主要論證
- 不使用條列符號 (bullet points) 於正文中
